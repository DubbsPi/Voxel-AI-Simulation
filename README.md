# Rust Voxel Engine
Made a kinda simple voxel engine using Vulkan in Rust.
WASD to move around and mouse to look. ESC to free the mouse

Fully procedurally generated terrain with caves. You can change the render distance/chunk size in the source code and then rebuild it.

To run simply download one of the two files from the release page (.exe for windows, the other for linux) and run it.
If you want to compile it yourself, simple clone the repository and run **cargo build --release** inside the project directory
